# The Invisible Trail

A React + JavaScript (JSX) cybersecurity investigation experience for SEASAW.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite (normally http://localhost:3000).

## Production build

```bash
npm run build
npm run preview
```

## Notes

- The application source and Vite configuration use JavaScript/JSX only. There are no `.ts`, `.tsx`, or TypeScript configuration files.
- The metadata challenge uses clearly labelled fictional EXIF values for demonstration. The displayed sample image does not contain those metadata values.
- Scores and leaderboard entries are stored in the current browser only; they are not shared between devices.
